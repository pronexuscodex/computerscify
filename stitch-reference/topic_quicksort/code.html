Sorting Algorithms

QuickSort: Divide and Conquer

QuickSort is an efficient, comparison-based, in-place sorting algorithm that follows the divide-and-conquer paradigm. Invented by Tony Hoare in 1959, it remains one of the most widely used sorting techniques due to its exceptional cache performance and speed.

Fig 1.1: The pivot-based partitioning process visualized as a spatial organization task.

The Pivot Strategy

The efficiency of QuickSort hinges entirely on the selection of a pivot element. The array is partitioned into two sub-arrays: elements smaller than the pivot and elements larger than the pivot.

psychology Partitioning

Rearrange the array so that elements less than pivot are on the left, and elements greater are on the right.

rebase_edit Recursion

Recursively apply the same logic to the resulting sub-arrays until the base case (single element) is reached.

quicksort.py 
def quicksort(arr):
    # Base case: arrays with 0 or 1 element are already sorted
    if len(arr) <= 1:
        return arr
    
    # Choose the middle element as the pivot
    pivot = arr[len(arr) // 2]
    
    # Partitioning logic
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    
    # Combine and recurse
    return quicksort(left) + middle + quicksort(right)

Best Case O(n log n)

Worst Case O(n²)
